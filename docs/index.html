05 Questions

Before you plug in.

"Windows protected your PC". Is it safe?
That's SmartScreen, shown for apps without a paid code-signing certificate. Click More info, then Run anyway. The release lists the exe's SHA-256 if you want to check it.
It won't connect, or finds no devices
Close YABE and other BACnet tools first; only one program can own UDP 47808, and BACon tells you who holds it. Across routers, register with a BBMD or add the controller by IP.
Does it read vendor properties?
Yes. Every property a controller reports, named with YABE's vendor mappings, like the Siemens Input/Output address [3019].
Can I use it without a network?
Save a site to a .bxsite file while connected, then open it anywhere to browse, query, export, and see schedules and alarms as they were read.

Questions

Before you break something.

Is it part of BACon?
No. It's its own exe and doesn't touch BACon, but they're made to go together: BACon only reads, and Rasher gives it something to read when you're not on site.
Can it run on the same PC as BACon or YABE?
Yes. Give each device an address of its own (Rasher tests it's free first) and it sits on UDP 47808 like a controller on the LAN. Or put devices on this PC's address on ports 47809 and up.
Why does it ask for administrator rights?
To add each device's address to the network adapter. The address is never used for this PC's own traffic and only lasts until the next restart, so a crash never leaves it behind.
Can a script or an agent drive it?
Yes. Everything the UI does goes through an HTTP API on 127.0.0.1:8048: start devices, read their state and activity, write points, switch faults. See the README.
"Windows protected your PC". Is it safe?
That's SmartScreen, shown for apps without a paid code-signing certificate. Click More info, then Run anyway. The release lists the exe's SHA-256 if you want to check it.
